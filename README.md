# ML Interview Prep Workspace

This workspace is designed to help you prepare for machine learning interviews. It includes:

- `notes/`: For theory, concepts, and summaries.
- `code_exercises/`: Practice problems and solutions in Python/Jupyter.
- `datasets/`: Sample datasets for hands-on practice.
- `resources/`: Useful links, papers, and reference materials.

## Getting Started
1. Use Python and Jupyter Notebooks for code exercises and explanations.
2. Organize your notes and code for easy review.
3. Version control is set up with Git—commit your progress regularly.

Happy learning!
